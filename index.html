ⓘ From browser to console
  1. Write your C code and export the project ZIP.
  2. Unzip it into a GitHub repository and let Actions build it.
  3. Download xenon.elf from the workflow artifact.
  4. Copy it to FAT32 USB and launch it with XeLL on a homebrew-capable Xbox 360.

Requires compatible homebrew-capable hardware/software. This does not run on a stock retail console.
